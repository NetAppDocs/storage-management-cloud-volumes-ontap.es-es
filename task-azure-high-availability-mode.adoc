= Habilitar el modo de alta disponibilidad para Cloud Volumes ONTAP en Azure
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Activa el modo de alta disponibilidad (HA) de Microsoft Azure para tu par de Cloud Volumes ONTAP HA a fin de reducir los tiempos de conmutación por error no planificados y admitir NFSv4. Este modo puede ofrecer un objetivo de tiempo de recuperación (RTO) de 60 segundos para los clientes CIFS y NFSv4 durante las conmutaciones por error no planificadas.

A partir de Cloud Volumes ONTAP 9.10.1, hemos reducido el tiempo de failover no planificado para los pares de HA de Cloud Volumes ONTAP que se ejecutan en Microsoft Azure y hemos añadido compatibilidad con NFSv4. Para que estas mejoras estén disponibles para Cloud Volumes ONTAP, debes habilitar la función HA en tu suscripción de Azure.

.Acerca de esta tarea
La NetApp Console muestra un mensaje cuando necesitas habilitar esta función en una suscripción de Azure. Ten en cuenta lo siguiente:

* Esta función funciona con ONTAP para reducir el tiempo de interrupción de las aplicaciones que perciben los clientes NFS durante las conmutaciones por error no planificadas. Habilitarla no indica ningún problema con la disponibilidad de tu par de alta disponibilidad (HA) de Cloud Volumes ONTAP.
* Activar esta función de Azure no interrumpe los pares de HA de Cloud Volumes ONTAP.
* Activar esta función en tu suscripción de Azure no afecta a otras VMs de tu entorno ni a ningún sistema de un solo nodo dentro de la misma suscripción.
* Durante las conmutaciones por error, Cloud Volumes ONTAP utiliza un equilibrador de carga interno de Azure para las LIF de gestión del clúster y de las SVM que dan servicio a los clientes CIFS y NFS.
* Al activar el modo HA, Console analiza el sistema cada 12 horas para actualizar las reglas internas de Azure Load Balancer.


.Pasos
Usa Azure CLI para habilitar la función como usuario de Azure con privilegios de _Owner_.

. https://docs.microsoft.com/en-us/azure/cloud-shell/quickstart["Acceda a Azure Cloud Shell desde el Portal de Azure"^]
. Registrar la función de modo de alta disponibilidad:
+
[source, azurecli]
----
az account set -s AZURE_SUBSCRIPTION_NAME_OR_ID
az feature register --name EnableHighAvailabilityMode --namespace Microsoft.Network
az provider register -n Microsoft.Network
----
. Opcionalmente, verifique que la función ahora esté registrada:
+
[source, azurecli]
----
az feature show --name EnableHighAvailabilityMode --namespace Microsoft.Network
----
+
La CLI de Azure debería devolver un resultado similar al siguiente:

+
[listing]
----
{
  "id": "/subscriptions/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx/providers/Microsoft.Features/providers/Microsoft.Network/features/EnableHighAvailabilityMode",
  "name": "Microsoft.Network/EnableHighAvailabilityMode",
  "properties": {
    "state": "Registered"
  },
  "type": "Microsoft.Features/providers/features"
}
----
