= Descubre las opciones de automatización de Cloud Volumes ONTAP
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Los equipos de DevOps utilizan diversas herramientas para automatizar la configuración y la administración de los entornos de ejecución de sus centros de datos. Además de NetApp Console, puedes utilizar varias de estas tecnologías para la automatización de Cloud Volumes ONTAP, incluidas las API de NetApp Console, los procedimientos de ONTAP CLI y herramientas de automatización como Ansible y Terraform. Las herramientas de automatización externas suelen basarse en un diseño de infraestructura como código (IaC).

Utiliza https://labondemand.netapp.com/["Lab on Demand"^] para practicar la automatización de Cloud Volumes ONTAP.



[[netapp-console-apis]]
== API de NetApp Console

La NetApp Console ofrece API de REST que puedes usar para administrar mediante programación los recursos de Cloud Volumes ONTAP. Las API admiten operaciones como crear y administrar sistemas Cloud Volumes ONTAP, así como añadir agregados y volúmenes en Amazon Web Services (AWS), Microsoft Azure (Azure) y Google Cloud. Las llamadas a la API disponibles varían según el proveedor de nube y el tipo de implementación, incluidas las configuraciones de un solo nodo y de alta disponibilidad (HA).

Puedes usar los flujos de trabajo de la API de Cloud Volumes ONTAP para automatizar una implementación típica y la posterior administración del almacenamiento. Algunos flujos de trabajo incluyen la preparación para la implementación, la creación de un sistema y la administración del almacenamiento, con flujos de trabajo específicos del proveedor para AWS, Azure y Google Cloud.

[[terraform]]
== Terraform

Terraform es una herramienta de orquestación de código abierto que utiliza archivos de configuración declarativos. NetApp ofrece un proveedor de Terraform para Cloud Volumes ONTAP. Puedes utilizarlo para automatizar e integrar tu infraestructura con IaC. Para obtener más información, consulta https://registry.terraform.io/providers/NetApp/netapp-cloudmanager/latest["NetApp proveedor de Terraform"^].
