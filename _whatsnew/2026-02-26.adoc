=== Compatibilidad con Google Infrastructure Manager para implementaciones en modo privado

Cloud Volumes ONTAP 9.16.1 y versiones posteriores ahora admiten  https://docs.cloud.google.com/infrastructure-manager/docs/overview["Google Cloud Infrastructure Manager"^] (IM) en lugar de  https://docs.cloud.google.com/deployment-manager/docs/deprecations["Cloud Deployment Manager"^] (DM) para nuevas implementaciones en modo privado en Google Cloud. Google está retirando Deployment Manager como servicio de infraestructura en favor de Infrastructure Manager, que es más avanzado.

A partir del 25 de febrero de 2026, Cloud Volumes ONTAP utilizará Infrastructure Manager para las implementaciones en modo privado, tanto nuevas como existentes. El flujo de trabajo básico depende de tu caso concreto:

[cols="1,4,1,1,1,1"]
|===
| Escenario | Acción | Nuevas APIs para el agente | Nuevos permisos para el agente | Nuevas API de Google Cloud para Cloud Volumes ONTAP | Recursos de documentación

Luego, convierte los sistemas de Cloud Volumes ONTAP existentes para que usen Infrastructure Manager.  a|

Consulta https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/reference-networking-gcp.html#infrastructure-manager-configuration-in-private-mode-or-protected-environments["Configuración de Infrastructure Manager en modo privado o en entornos protegidos"^].
