= Suscríbete e implementa la oferta independiente de Cloud Volumes ONTAP desde AWS Marketplace

[role="lead"]
Suscríbete a la oferta independiente de Cloud Volumes ONTAP en AWS Marketplace, implementa un agente de Console y crea tu primer sistema.

.Antes de empezar
Antes de empezar, asegúrate de que tienes:

* Una cuenta de NetApp Console o la información necesaria para crear una.
* Asegúrate de que la red del agente de Console cumpla los requisitos. link:https://docs.netapp.com/us-en/console-setup-admin/task-install-agent-aws-marketplace.html#step-1-set-up-networking["Infórmate sobre los requisitos de red del agente de Console"^]
* Una cuenta de AWS y una identidad con permiso para suscribirse a AWS Marketplace y aceptar las condiciones de la oferta.
+
Si eliges *Crear un rol para mí*, la identidad de AWS que envíe la pila de Quick Create de CloudFormation necesitará los permisos que se indican a continuación. Para usar la misma identidad tanto para suscribirte como para enviar la pila, asigna estos permisos antes de empezar. Si usas una identidad diferente para enviar la pila, asigna estos permisos a esa identidad. Estos permisos permiten a CloudFormation crear el rol de implementación; no son los permisos que usa el agente en ejecución.

+
[[aws-iam-role-permissions]]
.Permisos mínimos para la creación rápida de CloudFormation
[source, json]

{
	"Version": "2012-10-17",
	"Statement": [
		{
			"Sid": "CloudFormationStack",
			"Effect": "Allow",
			"Action": [

				"cloudformation:DeleteStack",

				"cloudformation:DescribeStackEvents",
				"cloudformation:GetTemplateSummary",
				"iam:CreateRole",
				"iam:DeleteRole",
				"iam:GetRole",
				"iam:PutRolePolicy",
				"iam:DeleteRolePolicy",
				"iam:GetRolePolicy",
				"iam:PassRole",
				"lambda:CreateFunction",
				"lambda:DeleteFunction",
				"lambda:GetFunction",
				"lambda:InvokeFunction"
			]
		}
	]
}
----




[[subscribe-to-the-standalone-cloud-volumes-ontap-offering-in-aws-marketplace]]
== Suscríbete a la oferta independiente de Cloud Volumes ONTAP en AWS Marketplace

Busca la oferta independiente de Cloud Volumes ONTAP en AWS Marketplace.

.Pasos
. Accede a AWS Marketplace utilizando tu cuenta de AWS con los permisos necesarios.
. Busca la oferta independiente de NetApp Cloud Volumes ONTAP. AWS Marketplace ofrece dos opciones para Cloud Volumes ONTAP:
+
** La oferta independiente de la suscripción anual a Cloud Volumes ONTAP
** La oferta combinada de NetApp Intelligent Service para los servicios de datos de NetApp y las suscripciones a Cloud Volumes ONTAP.


. Elige la oferta _independiente_. Estos pasos te guían durante la suscripción a la oferta independiente.
. Revisa los detalles del anuncio y las condiciones de precio.
. Suscríbete y finaliza el proceso de compra.
. Una vez que te hayas suscrito, selecciona *Configurar producto* para que se te redirija a la NetApp Console y así completar tu implementación.




[[sign-up-or-sign-in-to-netapp-console]]
== Regístrate o inicia sesión en NetApp Console

Continúa con la configuración en NetApp Console una vez que hayas completado la suscripción a Marketplace.

.Pasos
. En la página Console, selecciona una:
+
** *Regístrate* si eres un usuario nuevo.
** *Inicia sesión en NetApp Console* si ya tienes una cuenta.


. Si seleccionas *Registrarse*, completa los siguientes pasos:
+
.. Rellena los campos obligatorios.
.. Selecciona *Siguiente*.
.. Opcional: introduce tus datos de contacto, como la dirección, la ciudad, la provincia, el código postal y el número de teléfono.
.. Selecciona *Sign up*.
.. Acepta los términos de la licencia.
.. Verifica tu dirección de correo electrónico usando el mensaje de service@console.netapp.com.


. Inicia sesión en la Console y completa la autenticación.




[[create-your-organization]]
== Crea tu organización

Crea una organización solo si eres un usuario nuevo o si aún no perteneces a ninguna. Si ya perteneces a una organización, omite esta sección y continúa con <<Implementa un agente de Console en AWS>>.

Una organización te ayuda a gestionar usuarios, roles, permisos, licencias y sistemas.

.Pasos
. Introduce el nombre de una organización.
. Opcional: vincula una cuenta de NetApp Support Site (NSS).
. Selecciona *Crear*.




[[deploy-a-console-agent-in-aws]]
== Implementa un agente de Console en AWS

Una vez que tu suscripción esté asociada a NetApp Console, implementa un agente de Console para gestionar los recursos de AWS y los sistemas Cloud Volumes ONTAP.

.Antes de empezar
Revisa los requisitos de autorización y red de AWS antes de implementar el agente.

* Decide cómo autorizar a la Console para que instale el agente.
+
** Para la opción *Crear un rol para mí*, la identidad de AWS que envía la pila Quick Create de CloudFormation necesita permisos de administrador de AWS o los permisos mínimos de <<aws-iam-role-permissions,Ejemplo de JSON anterior>>.
** Para *Assume role* o *AWS keys*, consulta link:https://docs.netapp.com/us-en/console-setup-admin/task-install-agent-aws-console.html#aws-permissions-agent["Permisos de AWS para implementar un agente"^].


* Configura la red según link:https://docs.netapp.com/us-en/console-setup-admin/task-install-agent-aws-marketplace.html#step-1-set-up-networking["Requisitos de red para el agente de Console"^].


.Pasos
. En la página de bienvenida, selecciona *Reanudar configuración*.
+
The Console intenta asociar tu suscripción de marketplace con tu organización. Si la asociación automática falla, asocia tu suscripción manualmente. link:https://docs.netapp.com/us-en/console-licenses-subscriptions/task-manage-subscriptions.html["Aprende a gestionar las suscripciones"^].

+
Una vez asociada tu suscripción, Console te indica que implementes un agente de Console.

. Elige cómo autorizar a Console para implementar el agente:
+
Las credenciales de implementación autorizan a Console a implementar el agente. El agente en ejecución utiliza un rol de IAM independiente asociado a su instancia de EC2. Console puede crear ese rol o utilizar uno ya existente con los permisos necesarios. Consulta link:https://docs.netapp.com/us-en/console-setup-admin/reference-permissions-aws.html["Permisos de AWS para el agente de consola"^].

+
** Selecciona *Crear rol para mí* para que CloudFormation cree un rol que Console pueda asumir.
** Selecciona *Assume role* e introduce el ARN de un rol de IAM ya existente cuya política de confianza permita que la Console lo asuma y que cuente con los permisos de implementación necesarios.
** Selecciona *Claves de AWS* e introduce las claves de acceso de un usuario de IAM con los permisos de implementación necesarios.
+
[role="tabbed-block"]
====
.Crea un rol para mí (recomendado)
--
Para que Console cree el rol con Quick Create de CloudFormation, la identidad de AWS que envía la pila necesita permisos de administrador o los permisos mínimos del <<aws-iam-role-permissions,Ejemplo de JSON anterior>>.

... Selecciona *Crear un rol para mí*.
... Agrega el ID de la cuenta de AWS y, si lo deseas, el ID externo. La Console establece un nombre de rol por defecto.
... Selecciona *Abrir CloudFormation Quick Create*.
... En la página «Creación rápida» de AWS CloudFormation, acepta los términos y selecciona *Create stack*.
+
image:screenshot-stack-creation.png["width=35% Captura de pantalla de la página de creación de la pila de AWS CloudFormation donde introduces el ID de la cuenta de AWS y, opcionalmente, el ID externo para el rol de implementación del agente."]

... Cuando AWS configure el rol de IAM y genere el ARN, confirma y guarda el rol.


--
.Asumir rol
--
Si ya dispones de un rol con los permisos de AWS necesarios, indica su ARN para que Console pueda asumirlo y desplegar el agente. link:https://docs.netapp.com/us-en/console-setup-admin/task-install-agent-aws-console.html#aws-permissions-agent["Más información sobre cómo crear un rol"^].

... Selecciona *Assume role*.
+
Console crea un nombre para el rol asumido que puedes cambiar si quieres.

... Introduce el ARN del rol existente.
... Selecciona *Validate credentials*.


--
.Claves AWS
--
Si deseas utilizar claves de acceso para autorizar la implementación del agente, introduce tu clave de acceso y tu clave secreta de AWS. link:https://docs.netapp.com/us-en/console-setup-admin/task-install-agent-aws-console.html#aws-permissions-agent["Descubre cómo crear un rol para un usuario"^].

... Selecciona *las claves de AWS*.
... Introduce la clave de acceso y la clave secreta del rol que quieras utilizar.
... Selecciona *Validate credentials*.


--
====


. Configura los detalles de la implementación del agente, incluido el nombre de la instancia del agente y si la Console debe crear el rol de IAM para el agente en ejecución o usar un rol existente.
+
Cuando la Console crea el agente de la Console, crea un rol de IAM y un perfil para el agente, o usa un rol que tú proporcionas. Este rol incluye permisos que permiten al agente gestionar recursos de AWS. Asegúrate de que el rol esté actualizado a medida que se agreguen nuevos permisos en futuras versiones. link:https://docs.netapp.com/us-en/console-setup-admin/reference-permissions-aws.html["Más información sobre la política de IAM para el agente de Console"^].

. Configura la red seleccionando una VPC, una subred, un par de claves, el comportamiento de la IP pública y la configuración del proxy, si es necesario.
. Configura las reglas de tu grupo de seguridad para permitir el tráfico entrante por HTTP (80), HTTPS (443) y SSH (22) para solucionar problemas de acceso a la VM del agente.
+
link:https://docs.netapp.com/us-en/console-setup-admin/reference-ports-aws.html["Ver las reglas de los grupos de seguridad de AWS"^].

. Revisa los resúmenes de las secciones y selecciona *Add* para implementar el agente de Console.
+
Sigue el progreso de la implementación hasta que finalice. Puedes expandir los registros de eventos para revisar la actividad detallada.
