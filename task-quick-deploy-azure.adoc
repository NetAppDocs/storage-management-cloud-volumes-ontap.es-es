= Implementa Cloud Volumes ONTAP con Quick create
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Puedes implementar Cloud Volumes ONTAP en Amazon Web Services (AWS) y Microsoft Azure usando `Quick create` para un despliegue más rápido tanto en configuraciones de nodo único como de alta disponibilidad (HA). Este proceso simplificado reduce los pasos de implementación en comparación con el método avanzado al configurar automáticamente los valores predeterminados en una sola página y minimizar la navegación.

.Pasos
. Desde el menú de navegación de la izquierda, seleccione *Almacenamiento > Administración*.
. [[suscribirse]]En la página Canvas, haga clic en *Agregar sistema* y siga las instrucciones.
. Selecciona tu proveedor de cloud (*Amazon Web Services* o *Microsoft Azure*) > *Cloud Volumes ONTAP/Cloud Volumes ONTAP HA* > *Add new*. La opción *Quick create* está seleccionada por defecto.

.Detalles del sistema
. *Cuenta/credenciales del proveedor de la nube*: Los detalles de la cuenta y la suscripción se rellenan automáticamente en función de tu agente de la Console. Si tienes varias cuentas o suscripciones, selecciona la que quieres usar. Si un agente de la Console no está disponible, se te pedirá que https://docs.netapp.com/us-en/console-setup-admin/concept-agent-install-options.html["crear un agente de consola"^].
. *Nombre*: Introduce un nombre para tu sistema Cloud Volumes ONTAP (también llamado nombre del clúster). La NetApp Console usa el nombre del sistema (clúster) para nombrar el sistema Cloud Volumes ONTAP y la instancia de VM. También usa el nombre como prefijo para el grupo de seguridad predefinido, si eliges esa opción.
. *Credenciales de ONTAP*: Estas son las credenciales de la cuenta del administrador del clúster Cloud Volumes ONTAP. Puedes usar estas credenciales para conectarte a Cloud Volumes ONTAP a través de ONTAP System Manager o la CLI de ONTAP. Puedes mantener el nombre de usuario _admin_ predeterminado o cambiarlo por un nombre de usuario personalizado.
. *Etiquetas*: Las etiquetas son los metadatos de tus recursos de AWS o Azure. La Console añade las etiquetas a la instancia de Cloud Volumes ONTAP y a cada recurso asociado a la instancia. Puedes añadir hasta 15 etiquetas desde la interfaz de usuario al crear un sistema Cloud Volumes ONTAP, y luego puedes añadir más después de que se haya creado. Para más información, consulta:

.Implementación y configuración
. *Tipo de despliegue/topología*: Selecciona el tipo de despliegue que quieres usar: nodo único, alta disponibilidad (HA) en una sola zona de disponibilidad (AZ) o HA en varias AZ.
. *Configuración de la red*: Ingresa la información de red que registraste en la hoja de trabajo de planificación para regiones, VNets y subredes.
+
.. *Región*: Por defecto, se selecciona la región de la cuenta de cloud asociada con los recursos.
.. *Zona de disponibilidad*: Puedes seleccionar la zona de disponibilidad según el tipo de despliegue que elijas y si la región seleccionada admite la zona de disponibilidad.
.. *Subred*: Selecciona una subred para la región.
+
[role="tabbed-block"]
====
.Para AWS
--
*VPC*: Para AWS, introduce una VPC para la región con una subred según tu planificación

.Alta disponibilidad de AWS
Si seleccionaste una configuración de HA, introduce la siguiente información:

.HA en una sola AZ
... *Acceso del mediador*: especifique la información de acceso del mediador.  El mediador es una instancia separada que supervisa la salud del par HA y proporciona quórum en caso de falla.  Proporcione el nombre del par de claves para permitir que la instancia del mediador se conecte al servicio AWS EC2 y seleccione el método de conexión.


.HA en múltiples AZ
... *Zonas de disponibilidad y mediador*: seleccione las zonas de disponibilidad (AZ) para cada nodo y el mediador y las subredes correspondientes donde desea implementar el par HA de Cloud Volumes ONTAP .
... *IP flotantes*: si elige varias AZ, especifique las direcciones IP flotantes para los servicios NFS y CIFS y la administración de clústeres y SVM.  Las direcciones IP deben estar fuera del bloque CIDR para todas las VPC de la región.  Para obtener más detalles, consultelink:https://docs.netapp.com/us-en/bluexp-cloud-volumes-ontap/reference-networking-aws.html#requirements-for-ha-pairs-in-multiple-azs["Requisitos de red de AWS para Cloud Volumes ONTAP HA en varias zonas de disponibilidad"^] .
... *Acceso del mediador*: especifique la información de acceso del mediador.  El mediador es una instancia separada que supervisa la salud del par HA y proporciona quórum en caso de falla.  Proporcione el nombre del par de claves para permitir que la instancia del mediador se conecte al servicio AWS EC2 y seleccione el método de conexión.
... *Tablas de rutas*: si eligió varias AZ, seleccione las tablas de rutas que incluyan rutas a las direcciones IP flotantes.  Si tiene más de una tabla de rutas, es importante seleccionar las tablas de rutas correctas.  De lo contrario, es posible que algunos clientes no tengan acceso al par Cloud Volumes ONTAP HA.  Para obtener más información sobre las tablas de rutas, consulte la http://docs.aws.amazon.com/AmazonVPC/latest/UserGuide/VPC_Route_Tables.html["Documentación de AWS: Tablas de rutas"^] .

.Carga y servicios
. *Licencia*: Selecciona el tipo de licencia que quieres usar con este sistema Cloud Volumes ONTAP. Puedes elegir entre las licencias Professional, Essentials y Freemium. Para información sobre las diferentes licencias, consulta link:concept-licensing.html["Obtenga más información sobre las licencias de Cloud Volumes ONTAP"^].
. *Servicios y funciones de datos*: Mantenga los servicios habilitados o deshabilite los servicios que no desea utilizar con Cloud Volumes ONTAP.
+
** https://docs.netapp.com/us-en/data-services-data-classification/concept-classification.html["Obtenga más información sobre la clasificación de NetApp"^]
** https://docs.netapp.com/us-en/data-services-backup-recovery/concept-backup-to-cloud.html["Obtenga más información sobre NetApp Backup and Recovery"^]
** link:concept-worm.html["Obtenga más información sobre el almacenamiento WORM en Cloud Volumes ONTAP"]
+

TIP: Si desea utilizar WORM y niveles de datos, debe deshabilitar la copia de seguridad y recuperación e implementar un sistema Cloud Volumes ONTAP con la versión 9.8 o superior.



. *Cuenta del sitio de soporte de NetApp *: si tiene varias cuentas, seleccione la que desee utilizar.
. Verifique o edite los detalles ingresados y luego haga clic en *Crear*.


.Después de terminar
La consola implementa el sistema Cloud Volumes ONTAP .  Puede seguir el progreso en la página Auditoría.

Si experimentas algún problema al desplegar el sistema Cloud Volumes ONTAP, revisa el mensaje de error. También puedes seleccionar *Re-crear entorno* en el sistema para continuar con el despliegue usando el asistente de modo `Advanced`.


CAUTION: Una vez finalizado el proceso de despliegue, no modifiques las configuraciones de Cloud Volumes ONTAP generadas por el sistema en el portal de la nube de AWS o Azure, especialmente las etiquetas del sistema. Cualquier cambio realizado en estas configuraciones puede provocar un comportamiento inesperado o pérdida de datos.
